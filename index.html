Architecture médaillon

Un pipeline, quatre étapes clés.

Des traitements séparés et orchestrés pour passer de données collectées sur le web à des données préparées pour l’analyse.

ÉTAPE 01

Collecter

Récupération des calendriers, des effectifs et des informations sur les joueurs et les matchs.

ÉTAPE 02

Stocker en Bronze

Conservation des données récupérées dans leur zone brute, organisées par environnement.

ÉTAPE 03

Structurer en Silver

Nettoyage, transformation et structuration des données avec des traitements Python.

ÉTAPE 04

Préparer en Gold

Modélisation et agrégation avec dbt et DuckDB pour faciliter les analyses en aval.

Reproductibilité

Explorer le projet en local.

Une image Docker regroupe Airflow, le code du projet et un environnement dbt séparé. Les traitements se déclenchent depuis Airflow selon la configuration locale.

Lancer avec Docker

Construire l’image, créer un dossier pour les données locales et démarrer Airflow en environnement de développement.

docker build -t rugby-data .
mkdir -p data
docker run --rm -p 8080:8080 \
  -e AIRFLOW_VAR_ENV=DEV \
  -v "$PWD/data:/Volumes/rugby_data" \
  rugby-data airflow standalone

L’interface Airflow est disponible sur http://localhost:8080. Les chemins de données du projet sont configurés à partir de /Volumes/rugby_data.

Vérifier le code

Les contrôles automatisés du dépôt couvrent le lint, les tests, le parsing dbt, la construction Docker et un smoke test des DAGs.

  • Ruff pour les vérifications statiques
  • pytest pour les tests Python
  • dbt parse pour valider les modèles
  • Smoke test Docker sans accès réseau

Données & utilisation

Le code, pas les données collectées.

Ce projet de portfolio contient le code du pipeline, pas les jeux de données extraits. Les données collectées restent la propriété de leurs sources, notamment RugbyPass et AllRugby.

Toute collecte ou réutilisation doit respecter les conditions d’utilisation des sites concernés et les droits applicables. Ce dépôt n’est ni une API de données ni une autorisation de redistribuer leurs contenus.
